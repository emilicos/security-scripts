# Security Scripts

Colección de scripts de práctica enfocados en ciberseguridad, redes y automatización, desarrollados como parte de mi formación en Seguridad en Tecnologías de Información (LSTI - UANL).

## Proyectos

| Carpeta | Descripción | Tecnologías |
|---|---|---|
| [`ssh-auditor`](./ssh-auditor) | Prueba autenticación SSH contra hosts y registra resultados en log estructurado | Python, paramiko |
| [`hibp-email-checker`](./hibp-email-checker) | Verifica si un correo aparece en brechas de datos conocidas (API de Have I Been Pwned) | Python, requests |
| [`python-bash-pipeline`](./python-bash-pipeline) | Ejemplo de integración Python + Bash para procesar y exportar datos | Python, Bash, jq |

Cada carpeta tiene su propio README con detalles de uso.

## Sobre este repositorio

Estos scripts fueron desarrollados con fines educativos y de práctica personal. Antes de usarlos contra cualquier sistema, asegúrate de tener autorización explícita — varios de ellos (como el auditor SSH) están pensados exclusivamente para entornos de laboratorio propios.
